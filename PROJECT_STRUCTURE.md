# Project Structure

This repository is organized into purpose-based folders.

## Root
- `README.md`, `LICENSE`
- Active work-in-progress scripts that were intentionally left untouched:
  - `vMix-Manager_08.py`
  - `vMix-Manager_09.py`
  - `vMix-Manager_16.py`

## archive/iterations
Historical script snapshots and previous iterations.

## builds/v11
Packaging/export files for the v11 line.

## builds/v16
Packaging/export files for the v16 line.

## assets/icons
Icon files and icon-related notes.

## Why this layout
- Keeps root clean and focused.
- Separates historical code from active files.
- Groups build/export artifacts by version.
- Centralizes static assets.
